# Tibia Tools — Releases

Releases do app **Tibia Tools (Flutter)**.

O código-fonte fica no repositório privado; aqui ficam só os APKs publicados, para o botão **"Checar atualização"** do app conseguir enxergar e baixar a versão mais nova.

## Como atualizar

Baixe o APK da release mais recente nesta página e instale por cima da versão atual — seus dados e favoritos ficam intactos (mesma assinatura oficial).
